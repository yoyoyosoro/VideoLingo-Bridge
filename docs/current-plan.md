# 当前计划

## 目标
维护 VideoLingo Bridge 公开仓库的 `custom` 分支，保留现有自定义能力；当前无新增功能施工计划。后续官方同步由用户另行发起。

## 当前实现
- 官方 SRT、视频风格、单选 SRT / 多选 ZIP、选择记忆与原始名称保留。
- 多协议 LLM 接入、CC Switch 逻辑模型与六档推理、Provider / 映射缓存隔离。
- 已提交的 PyAV、NLTK 和虚拟环境修复纳入说明。

## 验收标准与下一步
- 本地 API 与字幕针对性回归通过；暂存区无真实 Key、私人配置、模型或运行产物。
- `origin/custom` 与本地 `custom` 同步；真实配置按原始字节保留。
- 完整视频、多线程长任务及上游真实推理强度仍需独立验收；本轮不新增付费请求。
